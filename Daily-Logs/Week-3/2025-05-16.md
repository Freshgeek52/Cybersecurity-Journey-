# Nmap Basics Lab Documentation  
**Date: May 16, 2025**  

---

## Core Concepts  
1. **Scanning & Enumeration**:  
   - **Scanning**: Identifying active hosts, open ports, and services on a network.  
   - **Enumeration**: Gathering detailed information (e.g., OS, service versions, vulnerabilities) about discovered hosts.  
2. **Nmap**: A network exploration and security auditing tool used for host discovery, port scanning, and service detection.  
3. **TCP Handshake**:  
   - **SYN** → **SYN/ACK** → **ACK** (establishes a connection).  

---

## Scan Types  
| Type         | Command | Description                                                                 |  
|--------------|---------|-----------------------------------------------------------------------------|  
| TCP Connect  | `-sT`   | Completes the full TCP handshake (default without root privileges).        |  
| SYN Stealth  | `-sS`   | Half-open scan (aborts after SYN/ACK; default with root privileges).       |  

---

## Port States  
- **Open**: Port is reachable, and a service is listening.  
- **Closed**: Port is reachable, but no service is listening.  
- **Filtered**: Port is unreachable (likely blocked by a firewall).  

---

## Key Nmap Options  
### Port Specification  
- `-p <ports>`: Scan specific ports (e.g., `-p 80,443`).  
- `--top-ports <N>`: Scan top `N` most common ports (e.g., `--top-ports 50`).  
- `-F`: Scan top 100 ports (fast mode).  

### Host Discovery  
- `-sn`: Ping scan (host discovery only, no port scanning).  
- `-Pn`: Skip host discovery (assume all hosts are up).  

### Fingerprinting  
- `-O`: Detect OS (use `--osscan-guess` for aggressive guessing).  
- `-sV`: Detect service/version running on open ports.  

### Timing  
- `-T0` (Paranoid) to `-T5` (Insane): Adjust scan speed (default: `-T3`).

## Guided Exercises  
### Part 1: Basic Scans  
1. **TCP Connect Scan**:  
   ```bash
   nmap 192.168.0.1  # Default scan (-sT) without root privileges.
   ```  
   - Detects open port **22** (SSH).  

2. **SYN Stealth Scan**:  
   ```bash
   sudo nmap 192.168.0.1  # Default scan (-sS) with root privileges.
   ```  
   - Identifies **1 open port**, **1 filtered port**, and **998 closed ports**.  

### Part 2: Target Network Enumeration  
1. **Host Discovery**:  
   ```bash
   sudo nmap -sn 192.168.0.0/24  # Finds 9 alive hosts.
   ```  

2. **Port Scanning**:  
   ```bash
   sudo nmap -Pn -F 192.168.0.2-100  # Scans top 100 ports on hosts 2–100.
   ```  

3. **Service/OS Detection**:  
   ```bash
   sudo nmap -sV 192.168.0.20 -p 21  # Finds "3.0.5" on port 21 (FTP).
   sudo nmap -O --osscan-guess 192.168.0.20  # Best OS guess: "CLabOS0.1".
   ```  

4. **Full Port Scan**:  
   ```bash
   sudo nmap -Pn -T5 -p- 192.168.0.20  # Scans all 65535 ports.
   ```  

5. **Slow Scan for Firewall Evasion**:  
   ```bash
   nmap -Pn -T1 192.168.0.2 -p 22,25,1000,2099,8080,8888  # Finds open ports summing to **8127**.
   ```

## Challenge Exercise (172.16.0.0/24 Network)  
1. **Host Discovery**:  
   ```bash
   nmap -sn 172.16.0.0/24  # Finds **2 hosts**.
   ```  

2. **Firewalled Host**:  
   - Likely IP: **172.16.0.32** (blocking probes).  

3. **Hidden Host**:  
   - IP: **172.16.0.16** (discovered via SYN scan with `-Pn`).  

4. **Legitimate Service**:  
   - Port **12345** running **sambasmbd4.6.2**.  

5. **Firewalled Host Ports**:  
   - Open ports: **80, 445, 23** (sum: `80 + 445 + 23 = 548`).
