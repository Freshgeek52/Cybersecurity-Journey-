# **Daily Documentation - May 13, 2025**  

## **1. Concepts Learned**  
- **Data Backup & Recovery**:  
  - **Backup Types**:  
    - **Full, Differential, Incremental**: Strategies balancing storage costs vs. recovery time.  
    - **Bare Metal**: Restores entire systems to new hardware/virtual environments.  
    - **Recovery Point Objective (RPO)**: Defines acceptable data loss thresholds.  
  - **Windows Server Backup (wbadmin)**: Tool for scheduling backups, restoring files/folders.  
- **Antivirus Basics**:  
  - **Malware Types**: Worms, ransomware, spyware, cryptojacking.  
  - **Detection Techniques**:  
    - **Signature-based**: Matches known malware patterns.  
    - **Heuristic/Behavior-based**: Analyzes code behavior (static/dynamic).  
    - **Adaptive**: Combines AI/ML for evolving threats.  
  - **Microsoft Defender**: Real-time protection, exclusions, PowerShell integration (`Start-MPScan`).
