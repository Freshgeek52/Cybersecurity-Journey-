# **Daily Documentation - May 15, 2025**  


## **1. Concepts Learned**  
- **Wireshark Fundamentals**:  
  - **Packet Analysis**: Intercepting and inspecting network traffic (ICMP, ARP, HTTP, FTP, Telnet).  
  - **GUI Components**:  
    - **Packet List**: Chronological capture overview.  
    - **Packet Details**: Protocol hierarchy (e.g., IPv4 → HTTP).  
    - **Packet Bytes**: Raw hexadecimal/ASCII data.  
  - **Filters**:  
    - **Capture Filters**: Limit captured traffic (e.g., `icmp`).  
    - **Display Filters**: Post-capture analysis (e.g., `http.cookie`, `ftp-data`).  
  - **Key Features**:  
    - **Follow TCP Stream**: Reconstruct sessions (e.g., Telnet credentials).  
    - **Export HTTP Objects**: Extract files (e.g., images, executables).
