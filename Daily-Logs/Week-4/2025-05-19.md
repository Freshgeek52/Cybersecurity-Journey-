## Core Concepts  
1. **VPN Overview**:  
   - Securely connects remote networks/users over untrusted networks (e.g., the Internet).  
   - Uses encryption for confidentiality, integrity, and authentication.  
   - Common protocols: PPTP, L2TP, SSTP, **IPsec**, OpenVPN.  

2. **IPsec**:  
   - Adds security to IP traffic via **AH** (authentication) and **ESP** (encryption).  
   - **Modes**:  
     - **Transport Mode**: Secures peer-to-peer connections (used for host-to-host).  
     - **Tunnel Mode**: Connects entire networks (site-to-site).  
   - **Phases**:  
     - **IKE Phase 1**: Establishes authentication and negotiates parameters (slow).  
     - **IKE Phase 2**: Creates encrypted tunnels for data transfer (fast).

## Guided Exercise: Site-to-Site VPN Setup  
### Part 1: Validate Connectivity  
1. **Access Firewall GUI**:  
   - Use the pfSense web interface (bookmark `pfSense - Login`) to configure rules.  
   - Pre-configured WAN rule allows **ICMP** (ping).  

2. **Test Connectivity**:  
   ```bash
   ping 203.0.113.5  # Verify Site-B firewall is reachable.
   ```  

### Part 2: Configure Site-A Firewall  
1. **Phase 1 (IKE) Configuration**:  
   - Remote Gateway: `203.0.113.5`  
   - Pre-Shared Key: `cybrary`  
   - Encryption: AES-256.  

2. **Phase 2 (IPsec) Configuration**:  
   - Remote Network: `10.10.10.0/24`  
   - Protocol: **ESP** (Encapsulation Security Protocol).  
   - Encryption: AES192-GCM.  

3. **Firewall Rules**:  
   - Allow **Any** protocol from `10.10.10.0/24` to `LAN net`.  

### Part 3: Configure Site-B Firewall  
1. **Phase 1 (IKE) Configuration**:  
   - Remote Gateway: `198.51.100.3`  
   - Pre-Shared Key: `cybrary`  
   - Encryption: AES-256.  

2. **Phase 2 (IPsec) Configuration**:  
   - Remote Network: `192.168.1.0/24`  
   - Protocol: **ESP**.  

3. **Firewall Rules**:  
   - Allow **Any** protocol from `192.168.1.0/24` to `LAN net`.  

### Part 4: Activate VPN & Verify  
1. **Start VPN Tunnel**:  
   - In pfSense, navigate to `Status > IPsec > Connect P1 and P2s`.  

2. **Test Connectivity**:  
   ```bash
   ping -c 8 10.10.10.10  # From Linux-A (192.168.1.0/24 network).
   ping -c 8 192.168.1.10  # From Linux-B (10.10.10.0/24 network).
   ```

## Answers to Tasks  
1. **Pre-configured WAN rule protocol**: `ICMP`  
2. **P2 Protocol on Site-A**: `ESP`  
3. **Local Host Address**: `198.51.100.3:500`  
4. **3rd Algorithm in Algor field**: `PRF_HMAC_SHA2_256`
